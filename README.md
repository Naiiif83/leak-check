# فحص تسرّب العدّاد

صفحة وحدة (`index.html`) يفحص فيها صاحب البيت تسرّب الماء بنفسه في ساعة، بدون سيرفر ولا اشتراك.

- **فحص العدّاد:** قراءتين ووقتهم، وتطلع النتيجة: كم لتر يضيع بالساعة وباليوم، وكم م³ بالشهر، وكم ريال زيادة على الفاتورة حسب الشرائح.
- **مكان التسرّب:** فحوصات للخزان العلوي والأرضي والماطور، وفحوصات سريعة داخل البيت (السيفون، العوّامة، السخان، المكيف الصحراوي، الحنفيات، الرطوبة، الري).
- **ملخص جاهز:** ينسخه صاحب البيت لشكوى الفاتورة المرتفعة أو للفني.
- **طلب فني:** يرسل بياناته وملخص الفحص على واتساب الرقم المحدد في `LEADS_WHATSAPP`.

البيانات تنحفظ على جهاز المستخدم بس. أسعار الشرائح قابلة للتعديل من الصفحة، وطابقها مع فاتورة حقيقية قبل النشر.

خطوات النشر والتسويق في [LAUNCH.md](LAUNCH.md).
